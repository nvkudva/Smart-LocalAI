What it does

A side panel that can actually touch the page.

Most assistants can only talk about a page. This one proposes the exact CSS or DOM change, waits for you to approve it, and undoes it on request.

◍

Ask about any page

Chat with a local model and get answers with page citations — click a citation and the page scrolls to the passage it came from.

✎

Restyle it, in words

“Make the headings blue, hide the cookie banner.” The model returns the exact rule; you approve the card; the page changes. Undo is one click.

▦

Pull the data out

Prices, specs, tables — one ask and the page comes back as clean Markdown you can copy into a sheet.

◎

Point at any element

Pick an element on the page and the agent targets it directly, so it edits the thing you meant instead of guessing.

⌘

Fits your workflow

Right-click for “Ask Smart LocalAI”, a prompt library with /, attachments, threads and per-chat exports.

◈

Yours to configure

Reasoning effort, theme, auto-summary, page context on or off, safe mode, and a smart model pick that skips embedding and moderation models.

Models

Bring your own model. Local ones come first.

The extension talks to whichever endpoint you pick and detects local servers automatically — no key, no account, no round trip to a cloud.

✦

▤
LM Studio
Auto-detected at http://localhost:1234/v1. Load a model in the GUI and it shows up in the picker.
◐
Ollama
Auto-detected at http://localhost:11434. Pull llama, qwen or mistral and pick it from the same menu.
⇄
Any OpenAI-compatible endpoint
Anthropic, OpenAI, Gemini, DeepSeek or your own gateway. Your key stays in this browser and is sent only to that endpoint.
How it works

Three steps, and you are in control of step two.

Ask in plain words

Type it, pick a suggestion chip, or right-click a selection. Page context rides along only while the Page ✓ toggle is on.

Review the card

The model returns an action card with the exact payload — the CSS, the selector, the value. Nothing runs until you press Apply.

Apply, or undo

The page changes in place. Every edit goes on an undo stack, so one click puts the page back exactly as it was.

Privacy

Nothing leaves your machine — unless you point it at a cloud model.

  • ✓ No telemetry, no analytics, no ads. There are no servers. The project can't read your data because it never receives it.
  • ✓ Keys live in chrome.storage.local. Your API key is stored in your browser profile and sent only to the endpoint you chose.
  • ✓ Page context is a toggle. Turn Page ✓ off and the page's text and DOM are not part of the request at all.
  • ✓ No model-generated code runs. The agent can only use the fixed set of actions the panel lists — CSS, text, clicks, fills, removals.

FAQ

The questions people actually ask.

Does it send my pages to a server?

Not if you use a local model. Chrome's built-in Gemini Nano runs on-device, and LM Studio or Ollama are reached over localhost on your own machine. If you point it at a cloud provider, the prompt and the page context you enabled go to that provider under your own key — that provider's privacy policy applies.

Do I need an API key?

No. With Chrome's built-in AI, LM Studio or Ollama there is no key at all. A key is only needed for the cloud providers, and it is stored in your browser profile, never on a server.

Can it change my pages without asking?

No. Safe mode is on by default: every mutating action arrives as a card and only runs when you press Apply. You can turn on auto-apply if you want it, and every applied change stays undoable.

Which sites work?

Any normal page. Chrome blocks scripting on chrome:// pages and on the Web Store itself, so editing is disabled there — the chat still works.

Can I read the source?

Yes — the full source is on GitHub, built with React and Vite as a Manifest V3 extension, and packaged with a single build command.
